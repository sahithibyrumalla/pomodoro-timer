# ✦ Pomodoro Timer

A fully interactive Pomodoro timer application designed with a cozy pixel-art aesthetic to make productivity feel more relaxing and engaging. This project combines animated visuals, smooth transitions, sound effects, and responsive design to create an enjoyable focus experience inspired by retro-style interfaces.

## ✦ Features

* 25-minute focus sessions
* Automatic short break system
* Pause and resume functionality
* Timer reset support
* Animated pixel cat states
* Transition screens such as:

  * “TIME’S UP!”
  * “BREAK TIME!”
  * “BREAK OVER!”
* Button click sound effects
* Countdown ticking audio
* Responsive layout for desktop and mobile devices
* Smooth UI interactions and hover animations

## ✦ Built With

* HTML5
* CSS3
* Vanilla JavaScript

## ✦ Design Inspiration

This project was created with a soft pixel-art theme inspired by cozy productivity setups, retro game aesthetics, and calming study environments.

## ✦ Project Goal

The goal of this project was to build a visually engaging Pomodoro timer while improving frontend development skills, JavaScript logic handling, UI state management, responsive design, and user experience design.
